# TXO Options Lab

台指選擇權 (TXO) 研究管線：定價 → 資料 → 隱波監控 → 回測 → paper trade。
完整規格見 `SPEC.md`；開發鐵律見 `CLAUDE.md`（**本 repo 禁止真實下單**）。

## 快速開始

```bash
uv sync --extra dev          # 或 pip install -e ".[dev]"
uv run pytest                # 全部測試需綠燈
```

**賣方三基準**：無條件、月月進場的收租策略在本樣本非正期望值——樣本涵蓋
2024-08 日圓套利平倉與 2025-04 關稅兩次股災（停損集中於此）與指數
17.2k→43.7k 大多頭（+154.6%，輾壓 call 邊）。

**B1 買方基準**：五項過四項，是本專案第一個正期望值策略（勝率 47%、
盈虧比 1:2.3、滑價加倍仍賺 44.7 萬），但 **MDD 26.5% > 20% → FAIL**。
回撤來自 2024-09~2025-02 盤整期的**連續 8 筆停損 −250,305**（低實現波動 →
theta 磨損），是買方性格的真實呈現，非實作錯誤。
註記（不作為翻案理由）：criteria 的 MDD 分母是「初始資金」；若改用業界
常見的「峰值權益」分母則為 18.4%。該定義在看資料前即寫死，事後更換等同
curve-fitting，故判決不變。

**B2（2026-08-03 執行）**：sizing 5%→2% 如預期把 MDD 從 26.5% 壓到 **8.5%**，
但同一筆預算下 `int(權益 × 2% / 權利金)` 在權利金較貴時歸零 → 進場被跳過，
筆數從 30 掉到 **25 < 30 → FAIL**。降風險是有效的，代價是樣本不足；
判決照 criteria 記錄，不因「其他四項全過」放行。

**B3（2026-08-03 執行）**：39 筆、每筆 +2,840、MDD 8.3%、佔用 0%、滑價×2 仍
+68,369——**五項全過，本專案第一個通過 pre-registered criteria 的策略**。
但證據力必須誠實標註：

- 這是對**同一份三年資料的第四次測試**（vertical / condor / strangle / B1 / B2 之後），
  多重測試下「總有一個會過」的機率不低，過關本身不等於有真實優勢
- 樣本期指數 17,178→43,727（**+154.6%**）是罕見大多頭，而 B3 的 200MA 閘門
  讓它**結構性做多**；它賺到的可能主要是 beta，不是選擇權的 edge
  （空頭樣本已於 S1 檢驗，見下節）
- 39 筆僅略高於 30 筆門檻，統計上仍屬小樣本；每筆 +2,840 對應的是
  2% 預算的小部位，總報酬 11.1% / 三年
- **最終仲裁是樣本外**（見下節）。在樣本外評估完成前，B3 只是「候選」

依規則：B3 通過 criteria → **Phase 6 paper trade 前提成立**（僅模擬；
鐵律 1 不因任何回測結果鬆動）。**criteria.py 未動過一字。**

## 空頭壓力測試 S1（2026-08-03 pre-registered，**跑之前寫死**）

**要回答的問題**：B3 的正報酬是選擇權操作的 edge，還是單純的多頭 beta？

**執行前提與已知限制（誠實記錄）**
- 引擎的 200 日均線**在回測視窗內暖機**（`px_series` 只裝視窗內的交易日），
  故視窗必須比空頭段早約一年開始，否則前 200 個交易日全被閘門擋掉、等於沒測
- ~~期交所資料下載專區僅提供**近三年**~~ → **已由實測推翻**：2026-08-03 在 VM 上
  `fetch --date 2022-06-15` 成功取得 TXO 1,386 列。原敘述是在連不到期交所的
  沙盒環境依公開文件推的，未經實測；`backfill` docstring 已更正

**視窗與口徑（不可事後調整）**
- 回測視窗 `2021-01-01 ~ 2023-07-31`：2021 供均線暖機、2022 為空頭主體、
  2023H1 為復原段，且與現有 DB（2023-08 起）無縫接續
- B3 參數完全沿用凍結版本，**一字不改**
- **criteria 不作為本測試的判決**：期間與樣本都不同。S1 是診斷，
  既**不能撤銷也不能加強**已記錄的 PASS

**判讀規則（先寫死，避免看到結果再編故事）**
1. 2022 進場筆數 ≈ 0、淨損益 ≈ 0 → 閘門如設計般讓策略退場。這是**防守成功**，
   但同時證實 B3 沒有全天候 edge，其報酬**條件於多頭市況**
2. 2022 多筆進場且大幅虧損 → 閘門在下跌段反覆假訊號（whipsaw），
   屬設計缺陷，B3 的可靠度應下修
3. 2022 少量進場、小額淨虧 → 正常的趨勢過濾摩擦成本；看金額相對多頭期獲利的比例

**同時記錄市況基準**（`txolab regime`，指數口徑同引擎）：期間指數報酬、
指數 MDD、在 200 日均線之上的日數佔比。既有樣本（2023-08~2026-07）一併補算，
用來量化「這份樣本對做多策略有多友善」——策略報酬要跟這個比才有意義。

### S1 結果（2026-08-03 執行，backfill 2021-01-04 ~ 2023-07-31，624 交易日）

| | S1 視窗 2021-01~2023-07 | 原樣本 2023-08~2026-07 |
|---|---|---|
| 指數（買進持有）報酬 | +15.0%（14,873 → 17,103） | +154.6%（17,178 → 43,727） |
| 指數最大回撤 | 31.5% | 29.5% |
| 在 200 日均線之上 | **51.5%**（219/425 日） | **85.3%**（451/529 日） |
| B3 平倉筆數 | 28 | 39 |
| B3 總淨損益 | **+5,615** | +110,773 |
| B3 每筆期望值 | **+201** | **+2,840** |
| B3 MDD | 7.9% | 8.3% |
| B3 滑價×2 總淨損益 | +3,053 | +68,369 |
| B3 略過的進場 | 0 | 104 |

**判讀：三條預寫規則都沒有完全命中，照實說明落在哪裡。**
進場頻率幾乎沒降（每交易日 0.045 筆 vs 0.054 筆），所以不是規則 1 的
「閘門讓策略退場」；沒有連續停損、MDD 反而更低（7.9%），所以不是規則 2 的
whipsaw；淨損益為正但趨近於零，所以也不是規則 3 的「小額淨虧」。

實際結果是第四種樣態：**照常交易，但每筆期望值從 +2,840 塌到 +201（−93%）**，
2.5 年總報酬 +0.56%。結論是 **B3 的優勢高度條件於強多頭市況**——在閘門只開
一半時間、且含 31.5% 崩跌的區間，它既沒有崩掉，也幾乎沒有賺到東西。
用「不會受重傷」形容是準確的；用「有全天候 edge」形容則不成立。

CLI 對 S1 印出的 `❌ 未通過 criteria`（28 筆 < 30）是工具的固定輸出；
依 pre-registration，**criteria 不是 S1 的判準**，該行不構成任何判決——
既不下修也不上修 B3 已記錄的 PASS。

風險調整對照（粗略 報酬/MDD）：S1 視窗買進持有 0.48、B3 0.07；
原樣本買進持有 5.24、B3 1.34。兩個區間裡買進持有都佔優。criteria 從未
包含「須勝過買進持有」，故不影響判決，但這是決定是否實際採用時的事實。
